AI 训练数据基础设施没有适用于所有规模和工作负载的唯一架构。对象存储、并行文件系统、数据访问层、元数据服务和缓存都会解决一类问题，同时引入新的成本和运维复杂度。

本章基于大规模数据生产与训练、混合文件、多云协同和模型分发场景，对自建 NAS、GPFS、CephFS、Alluxio 和 JuiceFS 五种路线进行比较，并说明当前选择 JuiceFS 的理由、边界和验证要求。
