AI 训练数据基础设施没有适用于所有规模和工作负载的唯一架构。对象存储、文件系统、元数据数据库、缓存、多云副本和 RDMA 都会解决一类问题，同时引入新的成本和运维复杂度。

本章从工作负载出发，说明关键组件应该在什么条件下引入，以及如何记录和复核架构决策。
